# Screen Translator v0.9.2 — Pixel Layout Implementation

本版本把已确认的 `v0.9.2b` 静态稿正式接入 PySide6 主程序。

## 固定设计基准

- 设计画布：1536 × 1024
- 主程序区域：1046 × 690
- 中间功能区：800 × 581
- 右侧预览区：420 × 690
- 底部数据/快捷键/托盘/控件区采用锁定坐标

## 实际接入

- 无边框像素窗口标题栏与窗口拖动
- 左侧导航选中状态使用独立像素素材
- 屏幕翻译 Hero / 语言 / 来源窗口 / 场景 / 操作 / 状态区域按已确认比例实现
- 场景按钮直接使用 normal / selected 像素素材
- 右栏字幕预览、迷你悬浮控制条、词汇释义采用批准版素材
- 小按钮使用 v0.9.2b 光学居中后的完整按钮素材，避免 Qt icon padding 造成偏移
- 底部数据管理、快捷键、托盘菜单与控件示例按静态稿坐标接入
- 其他功能页继续保留现有业务逻辑，通过左侧导航切换
